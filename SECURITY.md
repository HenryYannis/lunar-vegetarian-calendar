# 安全策略 / Security Policy

## 报告问题 / Reporting a problem

如果发现订阅文件被篡改、链接被劫持或其他安全问题，请**不要**公开提 Issue，到仓库的 **Security → Report a vulnerability** 私下提交，我会尽快处理。

If you find a tampered calendar file, a hijacked link, or any other security problem, please **do not** open a public issue. Use **Security → Report a vulnerability** on this repository to report it privately.

## 订阅建议 / Subscription notes

- 只使用 README 里列出的订阅链接（GitHub raw 或 jsDelivr）。
  Use only the subscription links listed in the README (GitHub raw or jsDelivr).
- 日历只含初一、十五事件和前一晚提醒，不会有链接或广告。看到其他内容请报告。
  The calendar only contains 1st/15th lunar-day events and the evening-before reminder, with no links or ads. Report anything else you see.
